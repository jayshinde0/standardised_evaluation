# Personalized Nutrition & Diet Plan Integration

## Overview
Integrated the LLM-generated personalized nutrition and diet plan into the Parent Dashboard's Physical Health section.

## Implementation

### Data Source
- **API Endpoint**: `GET /api/student/physical-health`
- **Generated By**: `generate_nutrition_plan()` function in `llm_service.py`
- **LLM**: Cerebras (gpt-oss-120b model)
- **Stored In**: Generated on-the-fly from latest physical test data

### Nutrition Plan Structure

```javascript
{
  ui_summary: string,           // Quick summary for dashboard display
  detailed_report: string,      // Full diet plan with meal suggestions
  visuals: [                    // Macronutrient distribution chart
    {
      chartType: "pie",
      chartTitle: "Ideal Daily Macro Target",
      labels: ["Carbohydrates", "Proteins", "Healthy Fats"],
      datasets: [{ data: [55, 25, 20] }]
    }
  ],
  is_fallback: boolean          // Whether this is fallback data
}
```

## Display Logic

### When Nutrition Plan Shows:
1. Child has completed at least one physical test
2. Physical test has metrics (height, weight, BMI)
3. Nutrition plan successfully generated by LLM

### When Not Shown:
- No physical tests completed
- Physical test data incomplete
- LLM generation failed (uses fallback)

## Technical Details

### API Call Flow
1. Parent Dashboard loads
2. Fetches child's physical health data
3. Backend generates nutrition plan on-the-fly
4. Returns structured plan with UI summary and detailed report
5. Dashboard displays summary and chart
6. Full plan available via button click

### Performance
- Nutrition plan generated asynchronously
- Cached in component state
- Only fetched once per dashboard load
- 30-second timeout for LLM generation

### Error Handling
- Graceful fallback if LLM fails
- Shows placeholder if no physical data
- Handles missing fields safely
- User-friendly error messages
